# Build artifacts were removed from this repo

Written 2026-09-07, while migrating to a new computer.

**Short version: nothing you need was deleted.** Every file removed is output that
PyInstaller regenerates from source in one command. The program itself — all of it — is
here and on GitHub.

---

## Why this had to happen

This repo could not be pushed to GitHub at all. Its history contained two ~300 MB files,
each committed three separate times, and **GitHub hard-rejects any file over 100 MB.**

That meant 17 commits of real work — including `366ed7f "Codex final use USE THIS"` from
19 July 2026 — existed nowhere but one laptop that was about to be decommissioned.

The repo was 1.9 GB. After removing build output it is **19 MB**. Same commits, same
source, same history.

## What was removed

15 files, all of them generated by PyInstaller. **Zero source files were touched.**

| File | Size | What it is |
|---|---|---|
| `dist/BeardTracker.exe` | 300.0 MB | The packaged executable |
| `build/BeardTracker/BeardTracker.pkg` | 299.7 MB | Intermediate bundle PyInstaller builds the exe from |
| `build/BeardTracker/PYZ-00.pyz` | 46.9 MB | Your Python modules, zipped |
| `build/BeardTracker/xref-BeardTracker.html` | 10.3 MB | Dependency cross-reference report |
| `build/BeardTracker/Analysis-00.toc` | 2.2 MB | Build manifest |
| `build/BeardTracker/base_library.zip` | 1.3 MB | Stdlib subset |
| `build/BeardTracker/PKG-00.toc`, `EXE-00.toc`, `PYZ-00.toc` | ~3.2 MB | Build manifests |
| `build/BeardTracker/warn-BeardTracker.txt` | 0.1 MB | Build warnings log |
| `build/BeardTracker/localpycs/*.pyc` | tiny | Compiled bytecode, 5 files |

Each of the two 300 MB files appeared three times across history, so roughly **1.8 GB of
duplicated build output** was being stored permanently.

## What was kept

Everything that matters:

- `beard_tracking.py` — the program
- `BeardTracker.spec` — the PyInstaller recipe, which is what rebuilds all of the above
- `requirements.txt`
- `run_beard_tracking.bat`
- `README.md`
- `alert.mp3`
- `models/hand_landmarker.task`, `models/face_landmarker.task`,
  `models/efficientdet_lite0.tflite`, `yolov8n-pose.pt` — the ML models

## How to get the removed files back

One command. From the repo root:

```bash
pip install -r requirements.txt
pyinstaller BeardTracker.spec
```

That recreates `build/` and `dist/BeardTracker.exe` exactly as they were. The `.spec`
file is the complete recipe — it is why none of that output ever needed to be committed.

If you only want to run the program without packaging it:

```bash
python beard_tracking.py
```

## What to do — simply

1. Clone the repo, or pull if you already have it.
2. Run `pip install -r requirements.txt`.
3. Run `python beard_tracking.py` to use it, or `pyinstaller BeardTracker.spec` to build
   the `.exe`.
4. **Do not commit `dist/` or `build/` again.** The `.gitignore` now blocks both, so this
   should not recur.

## Where the branches went

History was rewritten to strip the build output, which changes every commit hash. Nothing
was deleted from GitHub — the cleaned branches were pushed under their own names:

| Branch on GitHub | What it holds |
|---|---|
| `codex-backup` | Full 18-commit history, cleaned. **The most complete branch** |
| `cleaner` | Its 4 commits, cleaned |
| `Final_App-clean` | The rewritten `Final_App`. The original `Final_App` was left untouched, since force-pushing over it would have rewritten shared history |
| `new-device-migration-2026-09-07` | A single flattened snapshot of the source, made before the history rewrite. Redundant now, but harmless |
| `main`, `codex`, and the rest | Unchanged |

The original un-rewritten branches still exist in the local clone on the old machine and
in the nightly git bundle in OneDrive, if the old hashes are ever needed.

## One loose end

The old machine still has `dist/` (301 MB) and `build/` (365 MB) sitting on disk,
untracked. They are ignored by git now and safe to delete whenever — `pyinstaller
BeardTracker.spec` brings them straight back.
